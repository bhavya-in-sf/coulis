    THE PROBLEM

    Your AI doesn't know what good tastes like to you

    It sounds like everyone else.

    Same openers, same rhythm, same "game-changer." Readers scroll past it.

    It doesn't know how you write.

    You paste the same three examples and re-explain your style every session.

    Memory gets it wrong.

    It remembers the wrong thing, or applies one note to everything you write.

    Managing memory is a chore.

    Style files, prompts and notes to keep updated by hand, forever.

    HOW IT WORKS

    Four commands inside Claude

    Set up your taste

    Answer 5 questions and paste 3 things you're proud of. You get TASTE.md, your taste in one file you own.

    /tastee:setup
    Gate every draft

    Blocks numbers you never approved, banned phrases and house-rule breaks. Quotes each problem.

    /tastee:gate
    Get a real critique

    Eight separate scores, each quoting your draft. It rewrites only the weakest part, so you stay the author.

    /tastee:critique
    Teach it with edits

    Paste the AI draft and what you actually posted. It proposes rules, and you approve each one.

    /tastee:learn

    THE CRITIC STEP

    Firm on facts. Personal on voice. Never one score.

    Experts agree on whether writing is clear and backed by proof, and they disagree on taste. So Tastee holds the checkable half the same for everyone, and learns the taste half from you. Every axis is reported on its own, because one averaged number hides what to fix.

    Memory is like handing a chef your recipe card. A critic is someone who tastes the dish and sends it back if it's off.
