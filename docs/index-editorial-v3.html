LinkedIn now cuts the reach of posts that read as AI by about 40%. coulis is a free, open-source editor for AI drafts, not a detector: it reads every draft against your own facts and your own rules before it goes out, and never writes a word for you. Try it on a draft below.

    Inside Claude, it is a tool.

    1. An editor, not a writer. It says what is wrong and names the fix. The words stay yours.
    2. Install once. Two commands in Claude Code or Cursor. Your taste file lives on your Mac.
    3. Every draft gets checked. Claude calls coulis before it shows you anything. If it forgets, a hook sends it back.
    4. Approve facts in plain English. "Add 300 founders as a fact." It never asks again.
    5. Critique scores eight things. Clarity, proof, why you, the ask, hook, voice, boldness, rhythm. Never one number. Only the weakest line gets a rewrite.
