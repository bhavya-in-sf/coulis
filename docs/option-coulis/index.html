How it works

Three steps. Cheapest first, most personal last.

1Check

Fixed rules, no AI model, about 4 ms. Facts you never approved, the AI tells, a hook you already used. The answer: Send, Revise or Hold, with each problem quoted.

2Score

One number, 0 to 100: how much this draft sounds like you. Under 40 sounds like AI. 70 and up sounds like you.

3Learn

Change a draft and it proposes the rule it saw. You approve. The rule joins a taste file you own.
